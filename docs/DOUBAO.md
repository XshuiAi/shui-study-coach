# 豆包工作调用

## 安装

1. 下载发布包：<https://github.com/XshuiAi/shui-study-coach/releases/latest/download/shui-study-coach-0.2.1.zip>，解压。
2. 在豆包工作中进入技能上传入口，上传解压后得到的整个 `shui-study-coach` 文件夹。
3. 启用“小水学习陪练”，新建工作对话。

不同账户和版本的入口名称可能不同。GitHub 用于领取文件和查看说明；安装仍由每位使用者在自己的豆包工作里完成。

需要转发给别人时，直接发送仓库里的 [开始使用](../START-HERE.md) 内容即可。

## 首次体验

```text
使用小水学习陪练。带我体验内置的六级仔细阅读案例。先告诉我这次考什么、材料是什么、几道题；做完后按我的错题讲解，再换一篇材料出新题复测。
```

## 用自己的资料

```text
使用小水学习陪练。我在准备【考试或课程】，这次只复习【章节或题型】，有【15】分钟。请先确认你读到了哪些资料、题目和答案，再给我一组短练习。做完后告诉我错在哪里、原文依据是什么，并针对没稳住的点换题复测。
```

## 继续上次

```text
继续上次的小水学习陪练。这是我的练习记录。先告诉我上次仍答错的点，再用一小组新题检验；我只有 10 分钟。
```

网页不会自动把结果发送给 AI。完成网页练习后，点击“复制结果给 AI”，粘贴回同一个对话；或者导出完整记录后再上传。
