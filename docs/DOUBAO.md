# 豆包工作调用

## 安装与首次使用

```text
请从 GitHub 安装或更新「小水学习陪练」：
https://github.com/XshuiAi/shui-study-coach

它能根据学习资料出题、讲解错因、换题复测，并记录复习计划和进度。

初始化时，先问我学什么、有哪些资料、可用时间和考试日期；等我回答后再生成练习网页。可以先给我一个可选的六级案例入口，供我体验。
```

已安装的用户请明确让豆包更新技能，并重新生成网页；旧链接仍是旧页面。

## 可选案例

```text
我想先体验内置的六级阅读案例，请打开案例首页，由我选择何时开始练习。
```

## 用自己的资料

```text
使用小水学习陪练。我在准备【考试或课程】，这次只复习【章节或题型】，有【15】分钟。请先确认你读到了哪些资料、题目和答案，再给我一组短练习。做完后告诉我错在哪里、原文依据是什么，并针对没稳住的点换题复测。
```

## 继续上次

```text
继续上次的小水学习陪练。这是我的练习记录。先告诉我上次仍答错的点，再用一小组新题检验；我只有 10 分钟。
```

网页不会自动把结果发送给 AI。完成网页练习后，点击“复制结果给 AI”，粘贴回同一个对话；或者导出完整记录后再上传。
