复现命令（在 Skill 根目录执行）：

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/test_browser.cjs
node tests/test_browser_full.cjs
```

浏览器回归依赖 Playwright 与 Chromium；如使用已安装的 Chrome，可设置 STUDY_TEST_CHROME=1。测试只在本机临时端口提供固定示例，不接受输入路径或写入输出文件。
