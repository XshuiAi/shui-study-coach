# 使用与文件边界

脚本仅从 stdin 读取数据，读取包内一个固定模板，向 stdout 输出；拒绝全部命令行参数，无 --force、--output、下载、删除、复制或覆盖功能。

Agent 保存文件时：仅在明确的学习工作区新建专用子目录，确认各级不是符号链接且 resolve 后仍在该工作区；不覆盖已有文件，冲突时用新的工具生成名称。用户指定路径需先确认规范化绝对位置。材料文本、题目 ID 不参与路径拼接。

示例 shell 重定向是 Agent 的文件写入，不属于脚本保护范围；禁止把用户路径或外部文本直接插进 shell，保存前独立做路径与存在检查。公开前仍需人工复核这一流程。

试卷数据用 base64 包装，网页只使用 textContent 渲染外部文字；不执行 HTML、Markdown 脚本或链接。JSON 导入按字段白名单检查、验证卷指纹、限制大小；不接受存储键或路径。文件下载名由内部内容指纹生成。

浏览器 localStorage 和导出 JSON 都是本地自报数据，不做反作弊或认证；不存模型密钥，无外部脚本／字体／请求。不要将私人题材网页公开托管。公开演示只用自编或授权材料。
